# Mold Remediation Worksheet — Demo

Next.js demonstration for completing the **Mold Remediation Worksheet** on a phone and downloading a PDF that follows the original paper layout.

- No database, accounts, or backend
- Form data stays in the browser
- Optional device-only draft saving
- PDF is generated in the browser with `pdf-lib`

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
